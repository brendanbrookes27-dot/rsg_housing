# RSG Housing System v2.0 - Feature Overview

## 🎯 Core Features

### Property System
- **40+ Properties** strategically placed across the entire RedM map
- **6 Property Types**: Houses, Apartments, Cabins, Mansions, Saloons, Shops
- **Marker-Based Purchasing**: Visual green markers for available properties
- **Dynamic Blip System**: Map blips that update based on ownership status
- **Price Range**: $1,200 - $25,000 to suit all player budgets

### Saloon Business System
- **12 Dedicated Saloons** in major towns and settlements
- **Automatic Daily Earnings**: $100-$500 base income per day
- **Staff Management**: Hire bartenders (+10% earnings) and security (+5% earnings)
- **Earnings Collection**: Accumulate and collect profits over time
- **Business Locations**: Valentine, Saint Denis, Rhodes, Strawberry, Blackwater, and more

### Advanced Property Management
- **Ownership Types**: Purchase (permanent) or Rent (weekly payments)
- **Key System**: Give/remove keys to trusted players
- **Lock/Unlock**: Secure your properties
- **Storage Integration**: Property-based storage with configurable capacity
- **Wardrobe Access**: Clothing management within properties
